# Citations

This file provides a list of publications that can be cited when using
results obtained with the GENE-X code. Bibtex keys are provided that
correspond to entries in [the GENE-X bibliography file](./genex.bib).

## Base citation

Please cite [Michels2021] the first time you mention the GENE-X code in your
work.

## Most recent physics model

Please cite [Ulbl2025] (grid) or [Frei2025b] (spectral) if you want to refer
to the most recent physics model.

## Electromagnetic effects

Please cite [Michels2022] if electromagnetic effects such as perpendicular
magnetic fluctuations, magnetic flutter or magnetic induction is important
to your work.

## Collisions

Please cite [Ulbl2021] and/or [Ulbl2023] if plasma collisions are important
to your work.

## C++ and/or GPU-related features

Please cite [Trilaksono2025] if you use the auxiliary C++ layer and/or the
GPU features of the code.

## Spectral version

Please cite [Frei2025a] and/or [Frei2025b] if you use the velocity spectral
version of the code.
